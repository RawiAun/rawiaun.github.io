PearL portfolio - how to publish on GitHub Pages (free)
1. Create a GitHub repo (e.g. "portfolio"), upload everything in this folder (index.html + assets/).
2. Repo Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
3. In ~1 minute the site is live at https://<your-username>.github.io/portfolio/
4. Put that link on LinkedIn (Featured / Contact info) and in the resume PDF header.
To edit text: open index.html and search the sentence (English and Thai versions sit side by side).
Before sharing: check assets/Resume_Rawisara_Aunsinmun.pdf (it contains your phone number).
